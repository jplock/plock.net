I wanted to set up a Gemini server to bring back the web as it was when I first began using it in the 1990's. I was fortunate enough to attend a high school that had some Sun Microsystems SPARCstations available for student use. That's where I really began using Unix and eventually FreeBSD and Linux.

=> https://gemini.circumlunar.space/

To serve this content, I'm using the equally easy to use gmnisrv project created by Drew DeVault

=> https://sr.ht/~sircmpwn/gmnisrv/
=> https://drewdevault.com/

Gemini is just simplier. There are no ads. No banners. No tracking. No videos. No Google. No Facebook. Not even images (except for ASCII art!). It allows people to express information purely as text content.

I'm still using my Mastodon instance plock.social for status update and photo posting and keep plock.net focused around longer post content.

=> https://plock.social
